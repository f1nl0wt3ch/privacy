# Support

[English](../../support/) · [Suomi](../../fi/support/) · [Svenska](../../sv/support/) · [Tiếng Việt](../../vi/support/)

E-Mail: **tikki.dinh@gmail.com** · Wir antworten in der Regel innerhalb von 2 Werktagen.

Nennen Sie uns in Ihrer Nachricht Ihr Telefonmodell, Ihre iOS- oder Android-Version, die App-Version (Profil → unten auf dem Bildschirm) und, wenn es um Plus oder Einladungen geht, Ihre **Support-ID** (Profil → Support-ID → Support-ID teilen). **Senden Sie uns keine Finanzzahlen oder Passwörter.**

## Häufige Fragen

**Wo werden meine Daten gespeichert?**
Ihre Finanzdaten werden nur auf Ihrem Telefon gespeichert. Wir haben kein Kontosystem. Unser kleiner Server speichert nur Einladungscodes, Einladungsprämien und Gewährungen von kostenlosem Plus, verknüpft mit einer zufälligen Support-ID, niemals Ihre Finanzdaten. Siehe [Datenschutzerklärung](../privacy/).

**Ich habe mein Telefon verloren oder die App gelöscht. Können Sie meine Daten wiederherstellen?**
Nein, denn wir erhalten sie nie. Wenn Sie eine Gerätesicherung hatten (iCloud oder auf einem Computer), kann das Wiederherstellen des Telefons daraus die Daten zurückbringen.

**Wie lösche ich meine Daten?**
Öffnen Sie Profil → **Alle Daten löschen**. Auch das Löschen der App entfernt deren Daten vom Telefon.

**Was ist meine Support-ID?**
Eine zufällige ID, die die App auf Ihrem Telefon erzeugt (zum Beispiel `vung_3f9a…`). Sie ist nicht mit Ihrem Namen, Ihrer Telefonnummer oder Ihrer Apple-ID verknüpft. Sie finden sie unter Profil → **Support-ID**. Wir benötigen sie, um Ihre Einladungen nachzuschlagen oder Ihnen kostenloses Plus zu geben.

**Wie funktionieren Einladungen?**
Öffnen Sie Profil → **Freunde einladen** und teilen Sie Ihren Code. Wenn ein Freund Vung auf seinem eigenen iPhone installiert, die Einrichtung abschließt und Ihren Code eingibt, erhalten Sie 30 Tage Vung Plus kostenlos (bis zu 12 Monate pro Jahr). Codes funktionieren nur in der echten App auf einem echten iPhone. Die vollständigen Regeln stehen in den [Nutzungsbedingungen](../terms/).

**Mein Freund hat meinen Code verwendet, aber ich habe kein Plus erhalten.**
Öffnen Sie die App erneut; Prämien erscheinen auf dem Bildschirm „Übersicht“. Wenn innerhalb eines Tages nichts passiert, senden Sie uns Ihre Support-ID per E-Mail.

**Wie lösche ich die Daten auf Ihrem Server?**
Senden Sie uns Ihre Support-ID per E-Mail, am besten bevor Sie „Alle Daten löschen“ nutzen (dadurch wird eine neue ID erzeugt). Wir löschen Ihre Einladungsdatensätze, Codes und Gewährungen von kostenlosem Plus innerhalb eines Monats.

**Wie kündige ich mein Abonnement?**
iPhone: Einstellungen → Ihr Name → Abonnements → Vung. Android: Google Play → Zahlungen & Abos → Abos. Das Löschen der App kündigt das Abonnement nicht.

**Ich habe Plus gekauft, aber es ist nicht aktiv.**
Öffnen Sie Profil → **Käufe wiederherstellen**, während Sie mit derselben Apple-ID oder demselben Google-Konto angemeldet sind, mit dem Sie gekauft haben.

**Wie bekomme ich eine Erstattung?**
Apple: reportaproblem.apple.com. Google: Google-Play-Hilfe. Über Erstattungen entscheiden Apple oder Google.

**Wie ändere ich meine Werbeeinstellungen?**
Profil → **Datenschutz und Werbung**. Vung Plus entfernt jegliche Werbung.

**Benachrichtigungen kommen nicht an.**
Prüfen Sie, ob Benachrichtigungen für die App in den Telefoneinstellungen erlaubt sind und ob ein Fokus oder „Nicht stören“ sie blockiert. Erinnerungen werden auf Ihrem Telefon für die Uhrzeit geplant, die Sie im Profil gewählt haben (Standard 8:00).

**Ist die Punktzahl eine Finanzberatung?**
Nein. Sie ist ein Anhaltspunkt auf Grundlage der Zahlen, die Sie eingegeben haben. Siehe [Nutzungsbedingungen](../terms/).
